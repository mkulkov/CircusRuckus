# Clown Smash Animation Lab — параметры анимации

Документ описывает текущие параметры тестовой сцены `main.tscn`. Все значения доступны в Inspector у корневого узла `AnimationLab` и в runtime-панели, кроме общей длительности цикла.

## Цикл появления

| Параметр | Текущее значение | Описание |
| --- | ---: | --- |
| Pop Height | 325 px | Высота подъёма клоуна над коробкой. Одновременно задаёт рабочую длину растянутой пружины. |
| Pop Duration | 0,68 с | Длительность основного вылета: ускорение пружины, подъём клоуна и посадка после overshoot. |
| Overshoot | 46 px | Дополнительный подъём выше конечной верхней позиции перед возвратом в неё. |
| Idle / Wobble | 1,25 с | Длительность затухающего покачивания после вылета: наклон, squash/stretch, боковое смещение клоуна и наклон пружины. |
| Visible Time | 3,4 с | Время, когда клоун остаётся снаружи и доступен для клика. |
| Hide Duration | 0,62 с | Длительность возврата клоуна в коробку и сжатия пружины. |
| Cycle Seconds | 15 с | Полная длительность автоматического цикла от одного появления до следующего. Пауза рассчитывается автоматически из длительности фаз. |

## Удар молотка

| Параметр | Текущее значение | Описание |
| --- | ---: | --- |
| Hammer Swing Duration | 0,22 с | Общая длительность замаха и быстрого движения молотка к голове клоуна. |
| Hammer Rotation | 86° | Амплитуда поворота молотка в фазе замаха. |
| Impact Squash | 0,38 | Вертикальный масштаб клоуна в момент удара: чем меньше значение, тем сильнее сжатие. |
| Impact Duration | 0,18 с | Длительность основной фазы удара: squash, резкое сжатие пружины, вспышка и начало отскока. |

## Последовательность

Автоматический цикл: закрытая коробка → открытие крышки → короткое сжатие → быстрый вылет → overshoot → затухающее покачивание → ожидание → возврат в коробку → закрытие крышки → пауза.

Удар: клик по видимому клоуну → замах → удар с impact-вспышкой → squash клоуна и сжатие пружины → короткий отскок → проваливание в коробку → закрытие крышки → пауза и новый цикл.
