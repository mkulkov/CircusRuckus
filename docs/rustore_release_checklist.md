## Evidence boundary

Local tests and artifact inspection can establish project parsing, gameplay regressions,
package metadata, archive contents and cryptographic signing. They cannot establish
Console acceptance, Pay SDK sandbox callbacks, the store-generated APK set, data-safety
approval or moderation. Keep those items open until verified in RuStore Console/device.

The Console does not display AAB and screenshots uploaded through the Public API before
moderation. Their presence is verified through API status: version `1.0` / code `1`,
three phone screenshots, `DRAFT`, `MANUAL`, and no moderation date.
