# ClownSmash — политика монетизации, 2026-10-11

Общая политика существующих адаптеров Web Yandex/VK/OK, Android RuStore Pay + РСЯ, desktop Debug. Экспорт не выполнялся. SDK/API, товары, каталог/цены, платёжный сервер и кабинеты не менялись. Использованы локальные справочники навыка от 2026-10-07; повторное исследование не требовалось для смены игровых входов и упорядочивания существующих вызовов. Редакция правил VK 2026-03-17 не заявляется актуальной онлайн.

## Реализация

120 активных секунд между подтверждёнными показами; границы 5/10/15… по Continue и Retry после проигранной партии >=120 секунд; нет рекламы на New Game/обучении. Общий счётчик переносится между партиями в сессии. 60 секунд backoff ошибки, 30 секунд timeout до открытия. Баннер только обычный RUNNING, включая безопасное упорядочивание Web show/hide и отмену Android banner load. Покупка/restore remove_ads отключают оба формата. Нет rewarded, новых товаров, изменения баланса и активации аналитики.
