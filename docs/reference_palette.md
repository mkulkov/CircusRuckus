# Reference palette

- Deep circus red: `#8F2431`
- Bright prop red: `#DF3D35`
- Deep royal blue: `#203F7D`
- Box blue: `#1454A2`
- Gold trim: `#E79A25`
- Star yellow: `#FFC52F`
- Warm wood: `#A6532B`
- Orange bulb light: `#FFB43C`
- Deep cavity: `#1B0B1D`
- Warm highlight: `#FFE08A`
- Neutral text: `#FFF7E9`

The generated background and prop assets use these roles; procedural HUD and board accents reuse the same red/blue/gold/wood family.
