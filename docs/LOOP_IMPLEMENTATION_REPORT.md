## Поведение и ключевые файлы

- `scripts/gameplay/gameplay.gd`, `box_slot.gd`, `hammer_controller.gd`: читаемый этап OPENING доступен для тапа, результат фиксируется при принятии; повторные тапы, задержанный impact, новая цель и callback старой попытки не начисляют очки повторно. Анимационные параметры сохранены.
- `game_controller.gd`: +10 за scoring target, серия без множителя; Clock/Glutton сохраняют серию. Побег Glutton отнимает одну жизнь, обнуляет серию и счётчик промахов, без второго штрафа. Активное прошедшее время не откатывается от Clock.
- `spawn_director.gd`, `board_controller.gd`, `level_config.gd`, `data/levels/level_01..09.tres`: отдельные лимиты занятых коробок и нерешённых целей, гарантированные специальные цели только при положительном весе, постепенное введение Golden/Fast. Drunk имеет нулевой вес на всех уровнях и остаётся закрыт до человеческого playtest.
- `tutorial_controller.gd`: объяснение на первом реальном появлении; таймер и фоновые цели остановлены. Практика безопасна, простого показа текста недостаточно для завершения; Bomb изучается ожиданием. Обучение запоминается только в сессии, без новых save-полей. Повтор правил доступен из паузы.
- `scripts/ui/gameplay_hud.gd`, `session_overlay.gd`, `level_select.gd`, `localization/ui.csv`: обязательные цели, максимальная серия, предупреждения 1/3 и 2/3, добровольная цель после выполнения обязательных, причины поражения, финал девятого уровня и исторические рекорды. Старые рекорды сохранены и обозначены как исторические, их сопоставимость с новым балансом не обещается.
- `scripts/monetization/monetization_service.gd`, `monetization_adapter.gd`, `web_adapter.gd`: первый VK-вход пропускает рекламную проверку; недоступность, ошибка, отмена и timeout далее продолжают вход ровно один раз. Проверка прав remove_ads остаётся отдельной подтверждаемой процедурой, рекламная ошибка не выдаёт платёжных прав.
- `SPEC.md`, `AGENTS.md`, `ANIMATION_SPEC.md`, `PROGRESS.md` согласованы с принятыми исключениями. `tools/tune-loop.py` воспроизводит стартовую настройку ресурсов.
