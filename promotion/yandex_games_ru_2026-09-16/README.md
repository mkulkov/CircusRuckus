# Русские видео для повторной модерации Яндекс Игр

Комплект подготовлен 16 сентября 2026 года после замечания по локализации полей видео `[ru]`.

## Файлы для загрузки

| Поле в консоли | Файл | Проверенные параметры |
| --- | --- | --- |
| Вертикальное видео `[ru]` | `video/gameplay_vertical_ru_1080x1920.mp4` | H.264/AAC, 1080x1920, 9:16, 26.27 с, 13.33 МБ |
| Горизонтальное видео `[ru]` | `video/gameplay_horizontal_ru_1920x1080.mp4` | H.264/AAC, 1920x1080, 16:9, 26.27 с, 8.70 МБ |

Оба ролика созданы из одного свежего непрерывного рендера реального игрового процесса. Все значимые тексты в кадре русские; системного интерфейса, интерфейса Яндекс Игр и кнопки покупки нет. Горизонтальная версия сохраняет портретное игровое поле без обрезки и использует размытый фон из того же видеопотока.

`video/raw/gameplay_ru_540x960.avi` — воспроизводимый исходник Godot Movie Maker, не файл для загрузки. Скрипт записи: `tools/capture_ru_gameplay.gd`. Контактные листы предназначены только для проверки.

## Проверка

- оба MP4 полностью декодируются через FFmpeg без ошибок;
- длительность меньше 28 секунд;
- видео H.264, звук AAC 48 кГц stereo;
- контактные листы просмотрены, игровой интерфейс и HUD локализованы на русский;
- SHA-256 вертикального видео: `978070B442308F6FAA31EA6BC60FD31B4B746DF43A8C17AD570B0D8CAD448BAA`;
- SHA-256 горизонтального видео: `E5FA853C6DB3F6A7A0808CCAD323BA2C946A0D379C8B1653B99A3D41F1625047`.
