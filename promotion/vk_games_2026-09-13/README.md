# Материалы для VK Games / VK Mini Apps

Подготовлено 13 сентября 2026 года для игры **«Цирковой переполох»** (`Circus Ruckus`).

Основная документация: [Оформление игры в VK](https://dev.vk.ru/ru/games/settings/general/design).

| Поле VK | Файл | Размер | Формат | Вес |

### Скриншоты

Все скриншоты имеют размер 600×1200, формат JPEG и единую портретную ориентацию:

1. `screenshots/00_main_menu_600x1200.jpg` — главное меню.
2. `screenshots/01_gameplay_countdown_600x1200.jpg` — начало раунда.
3. `screenshots/02_gameplay_normal_clown_600x1200.jpg` — основной игровой процесс.
4. `screenshots/04_gameplay_results_600x1200.jpg` — итог раунда.
5. `screenshots/06_pause_menu_600x1200.jpg` — меню паузы.

Скриншоты сделаны из реальных состояний игры. Портретный кадр слегка обрезан только по бокам при переводе из 9:16 в 1:2; HUD, игровое поле и кнопки не обрезаны и не деформированы.

### Обновлённая галерея v2

Для страницы игры подготовлен новый набор в `screenshots_v2/`. Он сохраняет обязательные 600×1200 и единую портретную ориентацию, но использует PNG без потерь вместо сильно сжатого JPEG. Первые три позиции теперь показывают самые выразительные игровые состояния, а не меню и пустой отсчёт:

1. `screenshots_v2/00_hammer_impact_600x1200.png` — удар молотком и начисление очков.
2. `screenshots_v2/01_special_clowns_600x1200.png` — игровые типы клоунов.
3. `screenshots_v2/02_normal_clown_600x1200.png` — основной игровой процесс.
4. `screenshots_v2/03_startup_splash_600x1200.png` — заставка игры, адаптированная без искажения.

Заставка — дополнительный презентационный кадр по запросу; для галереи, где допускаются только кадры геймплея, её следует не загружать.

Для загрузки в VK использовать именно `screenshots_v2/` и сохранять указанный порядок. Старый JPEG-набор оставлен только для сравнения и отката.

## Проверка перед загрузкой

- Точные размеры и декодирование всех файлов проверены локально.
- Все JPEG-файлы меньше 500 КБ.
- Все PNG-файлы обновлённой галереи меньше 1 МБ.
- В материалах нет логотипов других магазинов или платформ.
- Русский текст находится только в материалах для русской локали.
- В кабинете VK перед отправкой на модерацию нужно ещё раз сверить подсказки у полей: страница документации `dev.vk.ru` не отдалась автоматизированному браузеру, поэтому изменения требований после 13 сентября 2026 года могут быть видны только в актуальном интерфейсе кабинета.

Тексты карточки и инструкция по заполнению находятся в `docs/vk_games_publication.md` в корне проекта.
